# TOML 多语言

内置 `locales/zh-CN.toml` 与 `locales/en-US.toml`，编译时嵌入二进制。`--locale-dir` 或偏好文件的 `locale_dir` 可加载完整外部包；同 locale 的外部文件替换内置包，不逐键混用。

```toml
locale = "en-US"
name = "English"

[messages]
"ui.ready" = "Ready"
"notice.saved" = "Configuration saved: {detail}"
```

以上仅展示格式，不能作为完整包加载。新增语言时：

1. 复制完整 en-US.toml，文件名与 locale 完全一致，例如 fr-FR.toml / fr-FR。
2. name 使用语言自称。
3. 翻译 messages 的值，保持键一致。
4. 保留命名占位符，可调整顺序，不要更名。
5. 运行 `cqs --locale-dir /path/to/locales languages` 验证，再用 `--lang fr-FR` 启动。

加载器拒绝重复 TOML 键、额外字段、缺键、额外消息键、空译文、损坏 TOML 和占位符不一致。参数只替换一次，参数中的花括号不会再解释成模板。

语言选择顺序为 CLI、CQS_LANG、偏好 TOML、系统 locale、英语。`zh_CN.UTF-8` 归一为 zh-CN，`en_US.UTF-8` 归一为 en-US。只有未支持的系统 locale 会使用英语；显式请求未知语言报错。

L 仅切换 TUI 本次会话；永久偏好写入 config.toml。操作 ID、CLI 参数名、枚举值、配置键和恢复记录不翻译。系统工具输出、I/O 诊断及 Clap 底层参数错误保留原文，应用提供本地化的外层说明。语言包无法加载时，用错误键及诊断报告启动失败。

`cargo test --locked` 检查所有操作标签、说明和字段，以及中文宽字符/英语长度不同的界面布局。
