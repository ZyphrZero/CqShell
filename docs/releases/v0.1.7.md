# CqShell v0.1.7

新增常用工具 `git` 与官方 GitHub CLI（`gh`）校验安装入口（总操作数增至 99 项），全面加固 Mihomo 热重载/持久化模式、自更新代理回退、SSH/公网 IP 安全校验，并深度打磨 Docker 6 标签工作台与核心 TUI 交互稳定性。

## 主要更新

### 新增功能
- **常用工具新增 `git` 与官方 `gh` CLI（`tools.git` / `tools.gh`）**：
  - `tools.git` 支持独立通过 `apt` 安装 Git；`tools.gh` 直连 `cli/cli` 官方 Releases，校验非草稿/非预发布、精确匹配 `amd64`/`arm64` `.deb` 资产名、SHA-256 摘要以及 `dpkg-deb` 包名与架构后安装，并自动接入全局 GitHub 国内加速代理（`--gh-proxy` / `github.proxy`）。
  - `tools.install` 一键全装扩展至 12 款常用工具，CqShell 结构化运维动作总数增至 **99 项**。
- **文档与预览**：中英文 README 补充桌面端与移动端 TUI 实机截图。

### 安全与运维能力修复
- **Mihomo 代理与 TUN**：
  - `clash.mode --set persist=on` 改为先通过控制器 `PATCH /configs` 应用成功后，再原子写入 `mixin.yaml` 与 `runtime.yaml`，防止接口失败导致磁盘状态与运行态不一致。
  - `clash.reload` 热重载前新增 `tun::validate_reload` 权限与设备归属校验，允许复用当前运行中 Mihomo 进程自身持有的 TUN 网卡。
  - `recover_interrupted_files` 放宽合法 profile 文件名校验，并在写回前先验证备份载荷完整性。
- **自更新代理回退**：`cqs update` 在 GitHub REST API 限流或被代理拒绝、回退至 `/releases/latest` 或 `/releases/tag/<TAG>` 重定向查询时，自动复用已配置的 GitHub 加速代理并正确剥离前缀解析标签，同时响应取消信号。
- **SSH、公网 IP 与路径边界**：
  - `ssh::candidate` 兼容 `Key=Value` 语法并忽略 `#` 注释行，避免误判 `Match` 块或误改注释。
  - `system.public_ip` 为 `curl` 强制增加 `--proto-redir =https`、`--connect-timeout` 与 `64 KiB` `--max-filesize` 上限，复用严格 IPv4/IPv6 校验并净化 ISP 控制字符，单项异常不再中断整次查询。
  - `clash.sub.import`、`clash.secret.set` 与 `ssh.key` 统一拒绝包含 `.` / `..` 相对路径段的路径。

### Docker 工作台与核心 TUI 稳定性提升
- **Docker 采集、日志流与安全边界**：
  - 自动关联容器挂载与卷的 `used_by` 引用关系，清理过期合成 Compose 项目并在容器清空时归零计数；Compose `up`/`pull` 强制校验配置文件存在性与参数合法性；`read_compose_file` 增加路径安全检查、有界 `256 KiB` 读取与控制字符净化；`docker exec` 在探测 Shell 前先校验参数，`docker top` 兼容含空格命令。
  - `LogStreamer` 校验容器 ID 与 Compose 参数防止选项注入，退出时完整排空尾行并报告非零退出码；离开 Docker 页后任务完成仅执行单次 `RefreshOnce`，并在操作/刷新/外部 exec 结束后失效 inspect 缓存；外部 `docker exec -it` 使用 RAII 守卫确保异常时也能恢复 TUI 终端状态。
- **Docker TUI 与核心工作台细节**：
  - 多选容器启停/暂停/删除及卷引用保护基于全部目标集合判定；严格收敛日志、详情与 Starship TOML 预览最大滚动值；Docker 页支持 `Alt+↑/↓` 调整侧栏分类顺序、全屏 `[` 呼出侧栏抽屉及 `i` 切换全屏详情。
  - 对齐顶层弹窗渲染优先级与事件分发栈顺序；修复一键优化「执行清单」CTA 按钮展示逻辑与顶栏运行状态胶囊点击命中区；点击外观抽屉外侧关闭时不再误触背景控件；窗口拉宽时自动收起冗余遮罩侧栏。

## 升级与使用示例

```bash
# 从旧版原地更新到 v0.1.7（国内环境可加 --gh-proxy default）
sudo cqs update

# 安装官方校验版 GitHub CLI（gh）与 git
sudo cqs run tools.git
sudo cqs run tools.gh --gh-proxy default
```
