# CqShell v0.1.7

新增常用工具 `git` 与官方 GitHub CLI（`gh`）安装项，并修复 Mihomo 配置持久化与热重载、自更新代理回退、Docker 工作台及 TUI 交互中的多项边界问题。

## 主要更新

- 新增 `tools.git`（APT 安装）与 `tools.gh`（从 `cli/cli` 官方 Release 下载对应架构 `.deb`，校验 SHA-256 与包信息后安装，支持 `--gh-proxy`）；`tools.install` 全量安装同步包含这两项。
- `clash.mode --set persist=on` 先确认控制器切换成功再写入 `mixin.yaml` 与 `runtime.yaml`；`clash.reload` 热重载前校验 TUN 权限并支持复用当前 Mihomo 进程已持有的 TUN 设备。
- `cqs update` 在 GitHub API 限流并回退至 Release 重定向查询时，继续使用已配置的 GitHub 加速代理并响应取消信号。
- SSH 配置解析兼容 `Key=Value` 语法并忽略注释行；`clash.sub.import`、`clash.secret.set` 与 `ssh.key` 拒绝含 `.` / `..` 的路径；公网 IP 查询增加 HTTPS 重定向限制、连接超时与响应大小上限。
- Docker 工作台正确关联数据卷引用、清理失效 Compose 项目，多选启停/删除与卷保护基于全部选中目标判定；修复日志流尾行读取与 `docker exec -it` 异常退出后的终端恢复。
- 修复 TUI 弹窗层级顺序、一键优化按钮显隐、顶栏状态胶囊点击命中区、面板滚动上限及外观抽屉外侧点击穿透问题。

## 升级与使用

```bash
sudo cqs update
sudo cqs run tools.git
sudo cqs run tools.gh --gh-proxy default
```
