# CqShell v0.2.1

`v0.2.1` 紧接 `v0.2.0` 发布，修复移动端 `TouchMedium` 2 行高列表滚动条下溢问题，并将 README 示例全面升级为离线逐帧录制的动态 GIF 演示。由于两版发布间隔很短，下方一并完整列出 `v0.2.1` 与 `v0.2.0` 的全部更新内容，方便从 `v0.1.8` 及更早版本直接升级。

## v0.2.1 修复与更新

- **修复移动端 `TouchMedium` 滚动条下溢**：在竖屏触控密度（如 `59×34`，列表单项占 2 行高度）下浏览长模块动作列表时，当条目数大于可见项数但小于视口行数，滚动条原先的 `rows.len() - visible_h` 会触发无符号减法下溢；现改为按实际可见项数（`geom.visual_rows.len()`）计算滑块高度与滚动上限，并补充回归测试。
- **离线逐帧渲染 README GIF 演示与录制工具**：移除旧版静态 PNG 截图，替换为 4 组由真实 `cqs` TUI 离线逐帧渲染的动态 GIF（桌面端全功能、Mihomo 6 标签工作台、Docker 6 标签工作台、移动端 `59×34` 触控体验），并保留跨平台一键录制脚本（`scripts/render_gifs.mjs` + `src/tui/gif_recorder.rs`）。
- **致谢补充**：在中英文 README 致谢列表中新增 `chen08209/FlClash`。

## 同时包含的 v0.2.0 主要更新

### 1. 原生双传输 MCP（stdio + Streamable HTTP）与结构化 JSON CLI
- **双传输 MCP 服务器**（零 `tokio`，保持单静态 musl 二进制）：
  - **stdio / SSH stdio（`cqs mcp`）**：支持 `2025-06-18` / `2025-03-26` / `2024-11-05` 协议协商，暴露 **13 项工具、5 项静态资源、2 项资源模板与 4 项 Prompt**，内置 `--read-only`、`--allow-danger`、`--allow-group`、`--deny-action` 边界护栏、全量密钥脱敏与零自动重启保证。
  - **Streamable HTTP + `0600` Bearer 密钥（`cqs mcp serve`）**：基于 `std::net::TcpListener` + 有界工作线程池，默认监听回环 `127.0.0.1:18765/mcp` 与严格只读模式；支持 `0600` 高熵 Bearer 密钥（`cqs mcp token status|init|rotate|set`）与**运行中零重启热轮换**、非回环绑定强制鉴权、`Origin` 防 DNS Rebinding 校验、分块传输（`chunked`）、`MCP-Session-Id` 会话管理与可选 `cqs-mcp.service` systemd 服务托管（`UMask=0077`，命令行零密钥）。
  - **一键安装与脱敏复制入口**：支持 `cqs mcp install / uninstall` 原子增量注册/卸载到 **Claude Code**（`~/.claude.json`）、**Codex CLI**（`~/.codex/config.toml`）、**Cursor**（`~/.cursor/mcp.json`）及任意 `--file` 自定义 JSON 文件；`cqs mcp config [--reveal]` 导出多格式片段；TUI `ai` 分组新增「MCP 服务与接入」区块与全局 **`Shift+M` 脱敏接入密钥卡**（屏幕始终遮罩、OSC 52 一键复制、原地轮换）；禁止通过 MCP 协议自我修改 MCP 控制面以杜绝提权。
- **结构化 JSON CLI**：新增 `cqs status [--section system|docker|mihomo|all] [--json]`、`cqs describe <id> [--json]`、`cqs choices <id> [--json]` 以及 `run` / `batch` 的 `--json`、`--dry-run`、`--params-json`。

### 2. 全新 Mihomo 6 标签可视化工作台与 SOCKS5 / 5h 入站
- 新增 `cqs mihomo` 独立可视化工作台（仪表盘 / 代理 / 配置 / 请求 / 规则 / 工具），支持全屏聚焦（`z`）、实时流量图谱、单节点与整组延迟测速排序、订阅配额与到期显示、外部 Providers 管理、13 项流媒体/AI 服务解锁检测、出站 IP 画像（支持隐藏 IP 持久化）、运行中配置自动热重载/重启及一键开启本机控制接口。
- 新增独立 `cqs-socks5` SOCKS5 / SOCKS5h 入站可视化配置与全局 `Shift+S` 脱敏凭据卡（非回环强制密码认证、屏幕始终遮罩、仅 OSC 52 复制）。
- 概览仪表盘与 Mihomo 仪表盘新增实时连接数统计（宿主机 TCP / UDP / `TIME_WAIT` 与 Mihomo 活跃连接 TCP / UDP 拆分）。

### 3. 移动端触控交互、Server 检测与稳定性加固
- 新增自适应触控密度（外观抽屉按 `D` 切换 `Auto` / `Compact` / `Touch`）与竖屏/窄屏底部拇指操作栏。
- 新增 `test.ai`（`ipforai.cc/sh` 只读 AI 服务与分流检测，默认关闭在线分享短链）。
- 统一二次确认为 `y/n` 流程，移除表单后冗余提示；修复 `crossterm 0.29` 在已断开 PTY 上的 100% CPU 死循环并补齐子进程 `ETXTBSY` 重试；全量消除渲染热路径每帧磁盘解析与空闲重绘开销。

### English Summary

CqShell `v0.2.1` follows shortly after `v0.2.0`, fixing an unsigned subtraction underflow in the mobile `TouchMedium` two-line list scrollbar renderer (with regression test coverage), replacing README static PNG screenshots with four offline frame-by-frame recorded TUI GIF demos alongside the reusable cross-platform recorder (`scripts/render_gifs.mjs` + `src/tui/gif_recorder.rs`), and crediting `chen08209/FlClash`.

It also includes the complete `v0.2.0` release: native dual-transport MCP interfaces (stdio + zero-`tokio` Streamable HTTP with `0600` Bearer tokens, hot token rotation, DNS-rebinding `Origin` checks, optional `cqs-mcp.service` systemd hosting, local installer for Claude Code / Codex CLI / Cursor / custom JSON, anti-self-escalation guardrails, and the `Shift+M` masked OSC 52 TUI access card), structured JSON CLI controls, the dedicated 6-tab Mihomo TUI workspace (`cqs mihomo`) with live traffic atlas, 13-service unlock and outbound IP profile checks, and masked SOCKS5 credential cards (`Shift+S`), host and Mihomo connection counts on dashboards, adaptive touch density with a mobile bottom thumb bar, `test.ai` (`ipforai.cc`), unified `y/n` confirmations, and PTY hangup / `ETXTBSY` stability hardening.
