# CqShell v0.1.5

重构双栏 TUI 与主题样式系统，新增 `cqs docker` 工作台、Mihomo 代理管理、GitHub 加速代理及在线自更新命令。

## 主要更新

- 主题拆分为 8 套配色与 8 套独立 UI 样式，支持通过 `cqs styles [--json]`、`--style`、`CQS_STYLE`、`config.toml` 或外观抽屉（`T`）自由组合，并提供透明背景（`B`）与减弱动效（`M`）开关。
- 重构概览仪表盘与工作台，新增全局命令面板（`/` / `Ctrl+K`）、鼠标划选复制（OSC 52）、纯文本视图（`V`）、分类排序持久化（`Alt+↑↓`）及最低 `40×16` 窄屏适配。
- 新增 `cqs docker` 六标签工作台，支持容器、Compose、镜像、数据卷、网络与守护进程管理，集成实时日志、资源监控、`docker exec -it`、多选操作、环境变量脱敏与分级清理向导。
- 集成 Mihomo 代理管理与 `cqs clashctl` / `cqs proxy-env` 兼容命令，支持核心安装、在线订阅与本地 YAML 导入、4 款 Web 面板、控制器测速/热重载、GeoData、DNS、TUN 及 systemd 托管。
- 新增 `cqs update`（`--check` 检测更新 / 校验 SHA-256 与架构后原子自更新）及全局 GitHub 加速代理（`github.proxy`、`--gh-proxy`、`CQS_GH_PROXY`、`GH_PROXY`）。
- 新增 `kernel.boot` 一次性 GRUB 启动内核切换；移除旧版独立 Shell 脚本实现。

## 安装与升级

```bash
GH_PROXY="https://gh-proxy.com"
curl -fsSL "${GH_PROXY%/}/https://raw.githubusercontent.com/ZyphrZero/CqShell/main/install.sh" | sudo bash -s -- --gh-proxy "$GH_PROXY" --version v0.1.5
cqs update --check
```
