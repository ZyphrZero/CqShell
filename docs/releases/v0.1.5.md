# CqShell v0.1.5

面向 Debian / Ubuntu 的大规模界面与核心能力升级：全面重构现代双栏 TUI、将主题拆分为独立配色与 UI 设计样式、新增 Docker 专属 6 标签工作台、全栈集成 Mihomo 代理与 `clashctl` 兼容、支持 GitHub 国内加速代理以及在线检测更新与原子自更新。

## 主要更新

### 界面、配色与 UI 样式解耦
- **8 套配色 × 8 套独立设计样式**：将主题彻底拆分为 **配色方案（Palette）** 与 **UI 样式（Style：`rounded` / `bento` / `editorial` / `hud` / `studio` / `atelier` / `heavy` / `ascii`）**，支持自由混搭；新增 `cqs styles [--json]`、`--style`、`CQS_STYLE` 与 `config.toml` 的 `style` 配置项。
- **双标签外观抽屉（`T`）与柔和微动效**：支持 `[配色]` / `[样式]` 实时预览、平滑 RGB 过渡、透明背景开关（`B`）与减弱动效模式（`M`）；纯 ASCII 样式与减弱动效下零动效开销。
- **概览仪表盘与资源进度条升级**：采用等高半高平滑渐变条与清晰行间留白、CPU 迷你波形、自动列宽对齐，并适配桌面双栏、80×24 紧凑屏及 59×24 / 40×16 移动端视口。
- **无焦点交互与效率增强**：新增全局命令搜索面板（`/` / `Ctrl+K`）、鼠标点选与划选复制（OSC 52）、纯文本日志视图（`V`）、自定义分类排序持久化（`Alt+↑↓`）及已有对象选择器（订阅/策略组/内核列表免手输）。

### Docker 专属 6 标签工作台（`cqs docker`）
- 新增全功能原生 Docker TUI（容器 / Compose / 镜像 / 卷 / 网络 / 守护进程），支持侧栏嵌入与全屏聚焦（`z` / `F`）切换。
- 支持容器启停/重启/暂停、原生 `docker exec -it` 终端、多选批量操作、实时流式/全屏日志、CPU/内存 Sparkline 与 `docker top`、敏感环境变量脱敏、可视化分级 Prune 向导（`Shift+P`）以及引用保护。

### Mihomo 代理与 `clashctl` 兼容
- 纯 Rust 集成 Mihomo 核心安装/更新、生命周期与 PID 归属校验、HTTPS 在线订阅及本地 YAML 导入（`clash.sub.import`），提交前强制执行 `mihomo -t` 校验并保留回滚基线。
- 内置 4 款 Web 控制台（Zashboard / MetaCubeXD / Yacd-Meta / Razord-Meta）、零外部进程控制器交互（热重载 / `rule|global|direct` 模式 / 并发测速 / 连接巡检）、GeoData 规则库更新、DNS / TUN / systemd 托管、`cqs proxy-env` 与 `cqs clashctl` 兼容命令。

### 更新机制、GitHub 加速与内核/系统增强
- **在线检测更新与命令自更新**：新增 `cqs update --check [--json]`、`sudo cqs update [--version TAG] [--force]`（别名 `self-update`）及 TUI `app.check_update` / `app.update`，直连 `ZyphrZero/CqShell` Releases，完整校验 SHA-256、ELF 架构与 `--version` 后原子替换。
- **全局 GitHub 国内加速代理**：新增 `github.proxy` 操作与 `--gh-proxy` / `CQS_GH_PROXY` / `GH_PROXY` 配置（支持 `default` 预设 `https://gh-proxy.com/`），覆盖 Mihomo、BBRv3 内核、Agent 工具、Starship 与自更新拉取；API 限流时自动回退。
- **内核管理**：新增 `kernel.boot` 一次性 GRUB 启动切换与安全检查；移除旧版独立 Shell 脚本实现，统一为纯 Rust 单二进制。

## 安装与升级

```bash
# 已有旧版可直接通过安装脚本升级（非 root 保留 sudo）
GH_PROXY="https://gh-proxy.com"
curl -fsSL "${GH_PROXY%/}/https://raw.githubusercontent.com/ZyphrZero/CqShell/main/install.sh" | sudo bash -s -- --gh-proxy "$GH_PROXY" --version v0.1.5

# 检测后续更新
cqs update --check
```
