# CqShell v0.1.8

修复退出 TUI 时终端鼠标追踪序列残留到父 Shell 提示符的问题。

## 主要更新

- 退出 TUI、进入纯文本视图或切换到外部交互命令时，先关闭终端鼠标追踪与备用屏幕并清空未读 TTY 输入缓冲，再恢复终端规范模式，消除退出后 `35;x;yM` 等鼠标序列输出到 Shell 的问题。
- 合并单帧内连续的鼠标移动、拖拽与窗口缩放事件，消除高回报率鼠标和 SSH 延迟下的输入队列积压。
- 退出时立即唤醒后台监控线程，缩短界面退出等待时间。
- 补充 Unix `SIGHUP` / `SIGQUIT` 信号捕获，终端挂断或收到退出信号时仍可正常恢复终端状态。

## 升级

```bash
sudo cqs update
```

如通过代理环境执行，可追加 `--gh-proxy default`。
