# CqShell v0.1.2

本版提供 Linux x86_64 / ARM64 Rust 安装包和独立的 `cqs.sh`，两个版本均支持 55 个操作。

## 主要更新

- 系统源接入固定版本、SHA-256 校验的 LinuxMirrors Lite，支持官方、清华、中科大和阿里云。
- 新增服务器端真实下载测速，可自动推荐最快的有效样本，也可手动指定镜像。
- 换源前备份，严格验证 APT 刷新，失败恢复；支持撤销最近一次换源和恢复未完成操作。安全更新使用官方源，不升级软件。
- 新增常用时区预设，同时保留自定义 IANA 时区输入。
- 内核安装成功后显示验证指引，并单独确认是否重启；`--yes` 不会自动同意重启。
- 大终端中的任务日志面板可随窗口扩展，统一使用“Agent 工具”名称。
- Rust 与 Shell 的界面、参数和恢复记录保持一致，发布附件包括两种程序形式。

## 使用示例

```bash
cqs run system.mirror.test
sudo cqs run system.mirror.apply --set mirror_site=auto
sudo cqs run system.mirror.apply --set mirror_site=ustc
sudo cqs run system.mirror.restore
```

独立 Shell 版将上述 `cqs` 替换为 `bash cqs.sh`。运行依赖为 Bash 4.4+、Python 3.11+ 及相应系统工具。

换源接入支持 Debian 12/13、Ubuntu 22.04/24.04/26.04 的 amd64/arm64。LinuxMirrors 按默认模板重建主源；混合第三方条目、版本别名及复杂自定义选项需要手动处理。完整换源验证已在隔离的 Debian 13 x86_64 环境进行；其他发行版和 ARM64 的生成器测试不替代完整系统验收。
