# CqShell v0.1.3

修复无法直连 GitHub 的设备不能完成二进制安装的问题。

- 安装器新增 `--gh-proxy HTTPS_URL`，兼容 `GH_PROXY` 环境变量，参数优先。
- 最新版本查询、安装包和 SHA-256 文件均经过指定代理；显式 `--version` 可跳过 API 查询。
- 代理模式通过 GitHub API 解析版本，避免下载中转服务拒绝 `/releases/latest` 网页的问题。
- HTTPS、禁止 HTTP 降级、校验文件名、SHA-256 与二进制版本检查保持启用；失败保留原安装。
- 无需新增 Python / jq 安装依赖。安装代理不配置系统代理，也不保存到 CqShell 运行配置。

## 无法直连 GitHub 时安装本版

```bash
GH_PROXY='https://gh-proxy.org/'
curl --disable --proto '=https' --proto-redir '=https' --tlsv1.2 -fL \
  "${GH_PROXY}https://raw.githubusercontent.com/ZyphrZero/CqShell/v0.1.3/install.sh" \
  -o install.sh && sudo bash install.sh --gh-proxy "$GH_PROXY" --version v0.1.3
```

显式传参可避免 `sudo` 清除环境变量；固定版本无需依赖代理的 API 支持和最新版本缓存。示例使用第三方下载中转，只有在信任该服务时使用。

发布附件仍包括 x86_64 / ARM64 Linux musl 安装包、`install.sh`、`cqs.sh` 及对应 SHA-256 文件。

This patch adds an explicit GitHub download proxy option to the installer. Version lookup, binary archives and checksums all use the selected HTTPS prefix. Pinned installs skip the API lookup. Integrity checks and preservation of existing installations remain enabled.
