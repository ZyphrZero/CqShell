# CqShell v0.1.6

增强 Docker 加速镜像源配置体验（支持多镜像源故障转移、内置常用预设、一键清空恢复直连与 TUI 快捷入口），并修复 Linux 并发启动子进程时偶发的 `ETXTBSY` 竞争问题。

## 主要更新

- **Docker 加速镜像源增强（`docker.mirror`）**：
  - 内置常用国内加速源预设：`recommended`（默认，4 源自动故障转移：`docker.1ms.run`、`docker.xuanyuan.me`、`docker.m.daocloud.io`、`docker.1panel.live`）以及单源 `1ms` / `xuanyuan` / `daocloud` / `1panel`。
  - 支持逗号、分号、空格或换行分隔多个镜像源，支持预设名与自定义 URL 混写并自动去重；严格校验 HTTP(S) 地址且报错不回显凭据。
  - 支持传入 `clear` / `off` / `none` / `direct` 安全移除 `daemon.json` 中的 `registry-mirrors` 恢复官方直连，保留其余配置项并经 `dockerd --validate` 校验后重启，失败自动回滚。
- **TUI 表单与 Docker 工作台快捷入口**：
  - 表单支持「自定义输入框 + 下方可点击预设标签」组合交互；打开 `设置 Docker 镜像源` 自动回填当前 `/etc/docker/daemon.json` 中的已有源。
  - Docker 工作台的 **镜像（Images）** 与 **守护进程（Daemon）** 页新增 `g` 快捷键与 `[g] 镜像源` 按钮；守护进程列表实时显示当前源数量或「直连」状态。
- **稳定性与文档改进**：
  - `runtime` 子进程启动（`spawn` / `status`）增加对 Linux 并发 `ETXTBSY (ExecutableFileBusy)` 的短退避重试，消除高并发与 CI 环境下的偶发失败。
  - 更新中英文 README、文档导航与部分模块结构整理。

## 升级与使用示例

```bash
# 从 v0.1.5 原地更新到 v0.1.6（国内环境可加 --gh-proxy default）
sudo cqs update

# 配置默认推荐 4 源故障转移组合
sudo cqs run docker.mirror

# 指定单源或预设 + 自定义源混写
sudo cqs run docker.mirror --set mirror=1ms,https://your-mirror.example.com

# 一键清空镜像源，恢复 Docker Hub 官方直连
sudo cqs run docker.mirror --set mirror=clear
```
