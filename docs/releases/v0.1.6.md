# CqShell v0.1.6

`docker.mirror` 支持多镜像源预设与一键恢复官方直连，并在 Docker 工作台中提供快捷入口。

## 主要更新

- `docker.mirror` 内置 `recommended`（4 源故障转移）及 `1ms`、`xuanyuan`、`daocloud`、`1panel` 预设，支持多源分隔混写与自动去重，传入 `clear` / `direct` 可移除 `registry-mirrors` 恢复官方直连。
- 支持自定义输入的表单字段同步展示可点击预设标签；打开 `docker.mirror` 自动回填 `/etc/docker/daemon.json` 现有配置。
- Docker 工作台的镜像与守护进程页新增 `g` 快捷键入口，并显示当前镜像源数量或直连状态。
- 子进程启动遇到瞬态 `ETXTBSY`（`ExecutableFileBusy`）时自动做短退避重试。

## 升级与使用

```bash
sudo cqs update
sudo cqs run docker.mirror
sudo cqs run docker.mirror --set mirror=1ms,https://your-mirror.example.com
sudo cqs run docker.mirror --set mirror=clear
```
