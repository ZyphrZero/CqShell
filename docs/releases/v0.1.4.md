# CqShell v0.1.4

安装器现在默认将程序安装为 `/usr/local/bin/cqs`，安装后直接输入 `cqs` 即可启动。

- 默认安装提供全局 `cqs` 命令，系统写操作使用 `sudo cqs`。
- 安装目录已在 PATH 中时，安装器显示 `Run: cqs --lang zh-CN`。
- 继续支持 `--install-dir` 自定义目录和 `--gh-proxy` 下载代理。
- README 中英文安装、启动和卸载说明同步更新。

## 安装

```bash
GH_PROXY="https://gh-proxy.org"
curl -fsSL "${GH_PROXY%/}/https://raw.githubusercontent.com/ZyphrZero/CqShell/main/install.sh" | sudo bash -s -- --gh-proxy "$GH_PROXY"
cqs
```

已是 root 用户时去掉 `sudo`。如果网关缓存的最新版本尚未更新，可以在安装命令末尾追加 `--version v0.1.4`。旧版默认安装用户升级后改用 `cqs` 启动。

验证覆盖默认目标目录选择、实际安装后的 PATH 命令查找、完整性校验及失败保留旧程序；另在私有挂载环境验证真实的默认全局安装，宿主命令路径保持原样。

The installer now defaults to `/usr/local/bin/cqs`, making `cqs` available as a global command after installation. Custom directories and GitHub download proxies remain supported. Release assets include Linux x86_64 and ARM64 binaries, both scripts, and SHA-256 files.
