system.info            System overview
  Read host, CPU, memory, disk, IP and BBR status.
system.public_ip       Public IP / ISP lookup
  Query IPv4, IPv6 and ISP over HTTPS. Contacts ip.sb and ipinfo.io only when selected.
system.update          Update packages
  Update apt metadata and upgrade packages under the shared kernel lock. Use noninteractive mode and preserve locally edited configuration. List services needing restart for later maintenance.
system.mirror.test     Benchmark system mirrors
  Download a 1 MiB repository index sample from each of four HTTPS mirrors on this server, at most 8 seconds per mirror. Rank measured transfer speed, including connection time; report failed samples. Does not change sources. Results are a short sample, not a sustained bandwidth guarantee.
system.mirror.apply    Change system mirror · LinuxMirrors
  Use pinned, SHA-256 verified LinuxMirrors Lite. Choose official, Tsinghua, USTC, Aliyun, or auto to benchmark then confirm the fastest successful sample. Rebuild standard APT sources with upstream component/source-package defaults; keep separate third-party files. Use official security repositories. Back up and restore configuration on failure; never upgrade packages.
  mirror_site=auto ["auto", "official", "tuna", "ustc", "aliyun"]
system.mirror.restore  Restore previous system sources
  Recover an interrupted mirror operation, or undo the last successful change. Refuse to overwrite later manual edits. Restore configuration before refreshing APT; an index refresh failure keeps the restored configuration.
system.clean           Clean system
  Standard: apt cache and journals older than 7 days. Full also deletes logs, temporary files, user caches and unused Docker data. All kernels are retained.
  scope=standard ["standard", "full"]
system.timezone        Set timezone

swap.remove            Remove swap
