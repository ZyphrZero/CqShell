system.info            系统概览
  读取主机、CPU、内存、磁盘、IP 及 BBR 状态。
system.public_ip       查询公网 IP / ISP
  通过 HTTPS 查询 IPv4、IPv6 和 ISP，仅在选中此操作时连接 ip.sb 和 ipinfo.io。
system.update          更新系统软件包
  在共享内核锁下更新 apt 索引并升级软件包。使用非交互模式，保留本机修改过的配置；列出需要重启的服务，供之后安排维护。
system.mirror.test     系统软件源测速
  在本机从四个 HTTPS 镜像站各下载 1 MiB 仓库索引样本，每站最多 8 秒。按包含建连时间的实际下载速度排名，并显示失败原因。不修改软件源；短时采样结果不保证持续带宽。
system.mirror.apply    更换系统软件源 · LinuxMirrors
  使用固定版本并校验 SHA-256 的 LinuxMirrors Lite。可选官方、清华、中科大、阿里云；auto 测速后确认最快的有效样本。按上游组件与源码仓库默认设置重建标准 APT 主源，保留独立第三方源文件。安全更新使用官方源。修改前备份，失败恢复配置，不升级软件。
  mirror_site=auto ["auto", "official", "tuna", "ustc", "aliyun"]
system.mirror.restore  恢复上次系统软件源
  恢复未完成的换源操作，或撤销最近一次成功换源。检测到后续人工修改时拒绝覆盖。先恢复配置再刷新 APT；索引刷新失败时仍保留已恢复的配置。
system.clean           清理系统
  标准清理：apt 缓存及超过 7 天的 journal。完整清理还会删除日志、临时文件、用户缓存和未使用的 Docker 数据。保留全部内核。
  scope=standard ["standard", "full"]
system.timezone        设置时区
  选择中国、新加坡、日本、美国东部/中部/山地/西部、英国、德国、法国等常用时区，或输入其他 IANA 时区名称。使用 timedatectl 应用。
  timezone=Asia/Shanghai ["Asia/Shanghai", "Asia/Hong_Kong", "Asia/Taipei", "Asia/Singapore", "Asia/Tokyo", "Asia/Seoul", "Asia/Bangkok", "Asia/Kolkata", "Asia/Dubai", "America/New_York", "America/Chicago", "America/Denver", "America/Los_Angeles", "America/Toronto", "Europe/London", "Europe/Berlin", "Europe/Paris", "Europe/Amsterdam", "Europe/Helsinki", "Europe/Moscow", "Australia/Sydney", "Australia/Perth", "Pacific/Auckland", "UTC"]
swap.create            创建 SWAP
  创建 /swapfile 并注册到 fstab；已有文件时拒绝覆盖。
  size_mb=2048 []
swap.auto              自动重建 SWAP
  根据物理内存计算容量并重建 /swapfile，操作成功前保留原文件。
swap.remove            删除 SWAP
  仅停用并删除 /swapfile 及其对应 fstab 条目。
system.fail2ban        安装 fail2ban
  安装 fail2ban，使用实际 SSH 端口和 systemd journal 配置受管理的 sshd jail。
ssh.port               修改 SSH 端口
  校验候选配置和实际监听，失败回退；外部防火墙可达性需另行验证。
  port=55520 []
ssh.key                配置 SSH 密钥登录
  向当前 HOME 导入公钥，测试新连接后关闭全局密码和键盘交互认证。不会打印私钥。
  public_key= []
bbr.status             查看 BBR 与队列状态
  检查运行中的实现版本、拥塞算法和网卡实际队列。
bbr.enable             启用当前内核的 BBR
  启用当前运行内核提供的 BBR；运行内核提供 BBRv3 时即启用 BBRv3。设置默认队列，并保留原始设置供还原。
  qdisc=fq ["fq", "fq_codel", "fq_pie", "cake"]
bbr.restore            撤销 BBR 设置
  恢复记录的运行值和原始持久配置。
tcp.tune               TCP 缓冲区调优
  根据带宽、RTT 和 cgroup 内存限制计算上限；应用、验证并保存，支持恢复。
  bandwidth=1000 []
  rtt=50 []
tcp.restore            撤销 TCP 调优
  恢复首次记录的 TCP 运行值和配置。
clash.install          安装 / 更新 Mihomo
  下载当前架构的官方 Mihomo Linux 二进制，校验发布元数据、SHA-256、ELF 架构和实际版本后，为当前用户原子安装。
  version= []
clash.status           查看 Mihomo 状态
  只读查看 Mihomo 进程、PID 和配置中的 HTTP/SOCKS 代理地址，不启动或修改服务。
clash.start            启动 Mihomo
  校验主配置与 Mixin YAML，原子发布运行配置，然后以带归属校验的 PID 记录启动 Mihomo。
clash.stop             停止 Mihomo
  向 CqShell 记录的 Mihomo 进程发送 SIGTERM 并等待退出。
clash.sub.list         查看订阅列表
  显示保存的订阅和当前选择，不下载内容，也不修改运行中的进程。
clash.sub.add          添加订阅
  下载 HTTPS 订阅，校验 YAML 和代理来源，原子保存，并可选择立即启用。
  name= []
  url= []
  use=off ["on", "off"]
clash.sub.use          选择订阅
  将已保存订阅原子复制为主配置；需要另行重启 Mihomo 才会应用。
  name= []
clash.sub.update       更新订阅
  重新下载并校验已保存订阅，原子替换其文件；如果它当前已选择，同时刷新主配置。
  name= []
clash.sub.remove       删除订阅
  删除已保存订阅；如果它是当前选择，同时删除对应主配置。
  name= []
clash.controller.status 查看控制器配置
  只读显示控制器地址及密钥是否已设置，不显示密钥。
clash.controller.configure 配置控制器地址
  停止 Mihomo 后设置 IP 或 localhost 与端口；校验成功后事务保存 Mixin。
  controller_address=127.0.0.1:9090 []
clash.proxies          查看策略组与节点
  通过配置的控制器查询策略组、节点和当前选择。
clash.proxy.select     切换策略组节点
  检查策略组及节点归属后通过控制器切换；不修改订阅配置。
  proxy_group= []
  proxy_node= []
clash.secret.generate  生成控制器密钥
  停止 Mihomo 后生成随机密钥并保存到私有 Mixin；不在日志显示内容。
clash.secret.set       从私有文件设置密钥
  停止 Mihomo 后读取私有文件中的密钥，避免将明文放入命令参数；Linux 文件须为 0600。
  secret_file= []
clash.secret.clear     清除控制器密钥
  停止 Mihomo 后清除认证密钥；仅允许回环控制器地址。
clash.panel.status     Web 控制台地址与状态
  检查静态面板资源，显示不含密钥的控制台 URL。回环地址需在本机或 SSH 隧道中访问。
clash.panel.install    安装 / 更新 Web 控制台
  下载官方 MetaCubeXD 稳定版，校验 SHA-256 并安全解压，验证后更新 external-ui；请先停止 Mihomo。
  version= []
clash.tun.status       查看 TUN 配置与归属
  只读查看 TUN 配置、链路及进程归属。
clash.tun.configure    配置 TUN 模式
  停止 Mihomo 后配置 TUN；启用要求原生 Linux、root、NET_ADMIN 和可用设备，拒绝 WSL/容器；启动时再次检查。

clash.logs             查看 / 跟随 Mihomo 日志
  读取有界日志尾部并隐藏密钥、代理认证及订阅参数；跟随模式可取消。

clash.service.remove   移除 systemd 托管服务

kernel.list            查看内核

kernel.install         安装 BBRv3 内核
  从 byJoey/Actions-bbr-v3 安装标准版或 Max 版 BBRv3 内核，支持最新匹配版本和指定版本。校验软件包、备份 GRUB 并更新引导；重启进入新内核后，在网络优化中设置 BBR 和队列。
  profile=standard ["standard", "max"]

kernel.boot            切换启动内核
  选择已安装的 Debian/Ubuntu 内核作为下一次启动项。交互模式会单独确认并重启；非交互 --yes 只设置启动项，稍后手动重启。TUI 从已安装内核列表中选择，CLI 填写“查看内核”显示的 release；只接受唯一匹配且文件完整的 GRUB 普通启动项。

kernel.remove          卸载未运行的 BBRv3 内核
  模拟卸载并拒绝移除额外软件包，保留运行内核和引导备份。
  release= []
